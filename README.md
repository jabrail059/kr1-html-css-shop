# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

На главной странице представлены преимущества магазина, карточки популярных товаров, отзывы с оценками, ответы на частые вопросы и форма оформления заявки в модальном окне.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product-*.html` — отдельные страницы товаров с описанием, характеристиками, рейтингом, отзывами и кнопкой заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — переиспользуемая карточка товара;
- `review-card` — карточка отзыва с рейтингом;
- `faq` — блок часто задаваемых вопросов;
- `back-to-top` — фиксированная ссылка «Наверх»;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка или ссылка в виде кнопки;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта.

При аудите классов селекторы, зависящие от вложенности (`.site-nav__list a`, `.form-field input`, `.filters-form fieldset`), заменены на классы элементов. Для активной ссылки навигации, выделенной карточки и вариантов кнопок используются модификаторы. `id` остаются для якорей и JavaScript; inline-стили не используются.

Варианты товарных карточек оформлены модификаторами `product-card--featured`, `product-card--new`, `product-card--sale` и `product-card--unavailable`. Для выделенного отзыва используется `review-card--featured`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.


## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение о заполненной заявке.

Кнопка «Заказать» доступна на страницах товаров в наличии и открывает форму с выбранным товаром. Форма проверяет поля и показывает подтверждение, но пока не отправляет данные на сервер.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- Flexbox для шапки, навигации и карточек;
- CSS Grid для адаптивной сетки товаров;
- БЭМ-классы элементов и модификаторов в шапке, навигации, карточках, каталоге и форме.
